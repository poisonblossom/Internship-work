# Bashwatch

Learnt some basic commands in bash scripting and worked on a SIEM (Security Information and Event Management) project where
I had to run serveral scripts to manage some various processes. SIEM is a cybersecurity solution that provides real-time monitoring, 
threat detection, incident response, and security log management across an organization's IT environment,
and with this projet I had to create simple scripts to cover at least two or more solutions.
The follolwing were the solutions I worked on;

1.Log analysis( took two snapshots of authentication log at 50 seconds apart and compared them)
2.Process monitoring( took two snapshots of current processes at 40 secs apart and compared them ).
3.Network Inspection (used various command to detect suspicious IPs and failed password attempts)
